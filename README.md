A modern, premium, attractive, and fully responsive Cafeteria & Restaurant website crafted with a warm, cozy coffee-and-cream aesthetic, glassmorphism cards, smooth animations, interactive online ordering, live order tracking, table reservations, and dedicated accessibility controls.

---

## 🌟 Key Highlights & Features

### 1. 🎨 Premium Modern Café Aesthetic
- **Warm Coffee & Cream Palette**: Rich roasted espresso, creamy steamed latte, toasted caramel, and amber gold accents.
- **Glassmorphism**: Frosted glass cards (`backdrop-filter: blur(16px)`), subtle borders, soft shadows, and card-lift hover effects.
- **Luxury Typography**: Google Fonts **Playfair Display** (editorial headline serif) paired with **Outfit** (clean, modern UI sans-serif).
- **Curated High-Resolution Visuals**: Appetizing, high-speed photography across coffees, breakfast plates, artisan pizzas, burgers, fresh juices, and pastries.

### 2. 🧭 Sticky Modern Navigation Bar
- Brand logo with warm coffee cup badge and tagline.
- Nav links: **Home**, **Menu**, **Offers**, **About Us**, **Gallery**, **Reserve Table**, **Reviews**, **Contact**.
- **Live Order Tracker shortcut** with real-time status progression.
- **Wishlist button** with dynamic badge counter.
- **Cart button** with live item count badge.
- **Dark / Light mode toggle** (Warm Creamy Latte mode ☀️ vs. Dark Roasted Espresso Nocturne mode 🌙).
- **Accessibility Controls (A11y)** modal trigger.
- **Login / Sign Up** modal with guest & member profile state.
- **Mobile Drawer Menu** with smooth backdrop-blur slide-in.

### 3. ☕ Home Page Hero Section
- Hero Headline: *“Fresh Food. Great Coffee. Good Moments.”*
- Interactive CTA buttons: **Explore Menu**, **Order Now**, and **Reserve Table**.
- Floating animated glass badges: `⭐ 4.9/5 Rating (2,400+ Reviews)` and `⏱️ Fresh & Hot in 15m`.
- Live stats counter row:
  - **50,000+** Happy Cups Served
  - **35+** Gourmet Recipes
  - **4.9 / 5** Customer Rating
  - **15 mins** Average Prep Time

### 4. 🍽️ Interactive Menu System
- **10 Filter Categories**:
  - All Delights
  - Coffee (Specialty Macchiato, Flat White, Nitro Cold Brew, Mocha Supreme)
  - Tea (Royal Masala Chai, Organic Uji Matcha, Hibiscus Berry Bliss)
  - Breakfast (Avocado Sourdough Toast, Eggs Benedict Royale, Golden Berry Pancakes)
  - Burgers (Truffle Mushroom Angus Burger, Fiery Paneer Burger, BBQ Crispy Chicken)
  - Pizza (Neapolitan Burrata Margherita, Rustic Pepperoni & Hot Honey, Garden Harvest Pesto)
  - Sandwiches (Grilled Caprese Panini, Smoked Turkey Club, Falafel Pita Pocket)
  - Snacks (Truffle Parmesan Hand-Cut Fries, Stuffed Jalapeño Poppers, Peri-Peri Tenders)
  - Fresh Juice (Sunshine Citrus Detox, Green Goddess Glow, Watermelon Mint Cooler)
  - Cakes & Desserts (Belgian Molten Choco Lava Cake, NY Salted Caramel Cheesecake, Warm Almond Croissant, Tiramisu Classico)
- **Live Instant Search**: Real-time filtering across names, descriptions, categories, and ingredients.
- **Dietary Filter Buttons**: All, Pure Vegetarian (green indicator dot), Non-Vegetarian (red indicator dot).
- **Sort Options**: Featured Favorites, Price: Low to High, Price: High to Low, Highest Rated.
- **Food Cards**:
  - High-res image with zoom hover effect.
  - Veg / Non-veg symbol indicator & Chef / Bestseller tags.
  - Price & discounted original price tag.
  - Star rating with review count.
  - Wishlist heart icon with micro-animation.
  - **Quick View Modal** detailing calories, preparation time, and key ingredients.
  - **Add to Cart** with animated badge increment & chime.

### 5. 🏷️ Special Offers & Countdown Timer
- **Live Countdown Banner**: Real-time ticking timer (Hours : Minutes : Seconds) for limited flash offers.
- **Promotional Offer Cards**:
  - *Morning Fuel Combo* (Artisan Coffee + Pastry/Avocado Toast)
  - *Campus Study Grind* (Flat 25% Off with code `STUDENT25`)
  - *BOGO Gourmet Pizza Weekend* (Code `WEEKENDPIZZA`)
  - *Happy Hour BOGO Brews* (Code `BOGOBREW`)
- **Copy Coupon Code**: One-click clipboard copy with instant toast alert feedback.

### 6. 📖 About Us Section
- Narrative of Café Bliss's 8+ years of roasting mastery.
- 4 Pillar Highlight Cards:
  1. *Farm-to-Cup Fresh* (Single-origin beans & organic pasture dairy)
  2. *Hygienic Open Kitchen* (Spotless sanitary preparation with live visibility)
  3. *Artisanal Baking* (Pure butter, slow fermentation, 0 artificial preservatives)
  4. *Warm Hospitality* (Passionate baristas welcoming every guest)

### 7. 📸 Modern Image Gallery & Lightbox
- Category filter tabs: All Photos, Coffee Craft, Artisan Food, Café Interior, Patisserie, Vibes & Smiles, Our Kitchen.
- Hover zoom animations with gradient overlays.
- Fullscreen **Interactive Lightbox Modal** with Next / Previous navigation, photo captions, keyboard arrow controls (← / →), and image counter.

### 8. 🛍️ Online Ordering & Live Tracking Experience
- **Slide-Over Cart Drawer**:
  - Item list with thumbnails, unit price, quantity increment / decrement (`+` / `-`), line totals, and trash remove button.
  - Dynamic calculations for Subtotal, Coupon Discount, 5% Café Tax, and Delivery Fee (Free on orders > $30).
  - Coupon Code validation input (`BLISS20`, `STUDENT25`, `WELCOME50`, `COFFEEFEVER`).
- **Checkout Modal**:
  - Choice of **Doorstep Delivery**, **Takeaway Pickup**, or **Dine-In at Table**.
  - Dynamic inputs for delivery street address or table number.
  - Payment method choices: Credit Card, Apple Pay / UPI, Cash on Delivery.
  - Order review summary and total breakdown.
- **Order Confirmation & Printable Receipt**:
  - Animated confirmation badge and generated Order Reference ID (e.g. `BLISS-784219`).
  - Itemized receipt breakdown with estimated arrival / pickup time.
  - One-click **Print Receipt** styling.
- **Live Order Tracking Modal**:
  - Animated 5-stage progress stepper:
    1. *Order Received & Confirmed*
    2. *Kitchen Cooking & Brewing*
    3. *Fresh Packaging & Quality Seal*
    4. *Out for Delivery / Counter Ready*
    5. *Delivered & Enjoyed!*
  - Simulated live status transitions and remaining ETA counter.

### 9. 🪑 Table Reservation System
- Online booking form: Full Name, Phone, Email, Date (min date restricted to today), Time slot, Number of Guests (1 to 12+), Seating preference (Indoor Cozy Booth, Sunlit Window, Garden Terrace Patio, Barista Counter), and Special Requests.
- Instant validation and generation of a **Booking Confirmation Voucher Modal** with Reference ID (e.g. `RES-48201`) and a simulated check-in QR code.

### 10. ⭐ Customer Reviews & Testimonials Carousel
- Automated rotating carousel with customer photos, names, titles, 5-star ratings, and authentic reviews.
- Dot indicators and previous / next navigation arrows.
- **“Write a Review” Interactive Modal**: Patrons can pick an interactive 1–5 star rating and publish their own review immediately to the live feed!

### 11. 📍 Contact & Location Section
- Café address, phone numbers, email, and opening hours.
- Stylized interactive Google Maps preview.
- Direct contact message inquiry form.
- Social media links with hover micro-animations.

### 12. 🎁 Premium Footer & Newsletter
- Newsletter subscription bar with instant validation and discount code gift.
- Quick navigation shortcuts & favorite bites direct jump.
- Operating hours breakdown and kitchen last call time.
- Sustainability pledge and accessibility policy notice.

### 13. ♿ Accessibility (A11y) & Audio Engine
- **Font Size Scaling**: `[A]` (Normal, 16px), `[A+]` (Large, 18px), `[A++]` (Extra Large, 20px).
- **High Contrast Mode**: Increases contrast ratios, borders, and text readability.
- **Reduced Motion Mode**: Instantly halts all floating keyframe animations, steam effects, and parallax transforms for motion-sensitive users.
- **Synthesized Audio Chimes**: Pleasant, warm musical bells generated via the browser's native Web Audio API (0 external audio file dependencies) on actions like adding to cart, applying coupons, and completing orders. Mute toggle included!

## 📁 File Structure

```
caftheria website/
├── index.html            # Main semantic HTML5 single-page application
├── README.md             # Documentation & feature guide
├── css/
│   ├── style.css         # Main stylesheet, theme variables, glassmorphism, components
│   ├── animations.css    # Keyframe animations, steam, floating badges, reduced-motion rules
│   └── responsive.css    # Mobile, tablet, desktop breakpoints, high contrast, font scaling
└── js/
    ├── data.js           # Menu items (30+ items across 9 categories), offers, coupons, reviews
    ├── a11y.js           # Accessibility engine (font scaler, high contrast, reduced motion, audio)
    ├── cart.js           # Cart engine, checkout, receipt, live 5-stage order tracker
    └── main.js           # App controller, wishlist, toast alerts, lightbox, reservations, auth
```

## 🚀 How to Run

1. Simply double-click **`index.html`** or right-click and open it in any modern browser (**Google Chrome**, **Microsoft Edge**, **Mozilla Firefox**, **Safari**).
2. No Node.js, Python, npm, or build tools are required. Everything is 100% self-contained, lightweight, and lightning-fast!
